# 검증용 테스트 (VishasBody)

## 자동 테스트
- 위치: `test/test_<모듈>.py` (커밋 대상), 프레임워크: `unittest`(표준 라이브러리).
- 실행: `<py> -B -m unittest discover -s test` (`<py>`는 `simple-test`의 "Python"과 같다).
- 가져오기: 테스트 파일에서 `src/`를 `sys.path`에 넣는 방식은 기존 `test/test_body_packet.py`를 따른다.
- 경계값(이 프로젝트에서 꼭 넣을 것):
  - 패킷: 검출 없음(flags 0), 한쪽 손만, 루트 위치 무효, 패킷 전체 크기, 헤더 바이트 값(시그니처·종류·버전)
  - 송신: 등록 전 바이너리 버림, 재접속 후 재등록 → 가짜 서버(`127.0.0.1`, 임의 포트)로
- 쓰지 않는 것: 웹캠, 실제 서버, 모델 파일(`models/`는 git 제외라 다른 PC에 없음), GPU.

## 사용자 시나리오 로그
- 파일: `logs/qa_scenario.log` (git 제외: `.gitignore`의 `logs/`).
- **아직 이 파일에 쓰는 코드가 없다.** 시나리오가 필요하면 qa는 로그 지점 `[Proposal]` 이슈부터 올린다.
- 비우기: 실행 전에 사용자가 파일을 지운다(트래커가 시작할 때 새로 만든다).
- 웹캠은 실행 PC에서만 쓸 수 있다. 실행 PC의 로그 파일은 git에 올라가지 않으므로, 사용자가 이 PC의 같은 경로로 복사하거나 내용을 채팅에 붙여 넣은 뒤 판정을 요청한다.
- 로그에 서버 주소·카메라 이미지를 남기지 않는다.
